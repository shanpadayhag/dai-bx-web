Version 2 rewrites DaiBX in **SolidJS** with the same design, the same features and the same data.

- The production bundle is about **3.4× smaller** than the Angular version.
- Checking off a task re-renders only that task.
- Contrast, focus and labels now meet **WCAG AA**.
- Timers enforce their limits, so a timer can’t run past the end you set.
